# Sports Wear – web chọn mẫu áo thể thao

Trang demo cho shop đồng phục thể thao: áo bóng đá, bóng chuyền, bóng rổ, cầu lông và polo.

- Hero dạng "cửa đường hầm" mở ra sân vận động khi cuộn trang
- Bộ thẻ 5 bộ môn kéo/vuốt, catalogue 20 mẫu áo
- Phòng thiết kế: đổi họa tiết, màu, tên, số, số lượng (từ 5 bộ), gửi đơn qua Zalo

Chỉ có một file tĩnh: mở `sports-wear.html` bằng trình duyệt là chạy, không cần cài đặt.
